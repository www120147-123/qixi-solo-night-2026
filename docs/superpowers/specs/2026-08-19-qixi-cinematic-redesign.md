# 《鹊桥借我一晚》电影化重构规格

## 目标

把现有“静态章节切换”重构成一条连续、可交互、由音乐和共享物体驱动的七夕短片。开场先让用户相信这是一个认真浪漫的牛郎织女故事，再在相触前用静音和黑场完成反差，进入“一个人怎么过七夕”的单人宇宙。

成功标准不是动画数量，而是：角色持续表演、镜头有节奏、章节之间存在视觉因果、互动会改变画面状态、手机与桌面都保持完整叙事。

## 六幕结构

### 0. 入夜 / 3-6 秒

- 米白极简 Loader，只保留标题、真实加载进度和声音进入按钮。
- 用户点击后解锁音频，米白圆幕收缩为夜空中的月亮。
- 固定 HUD 与纵向进度轨在入夜后出现，保持全站连续。

### 1. 鹊桥 / 24 秒主时间线

- `0-2.5s`：黑场中一颗星点亮，银河与云层缓慢显影。
- `2.5-7s`：至少 16 只喜鹊从四周沿弧线飞来，逐段组成桥。
- `5-15s`：牛郎织女从左右两岸各走 6-8 步；头部起伏、手臂与腿交替摆动、衣袖有跟随动作。
- `15-19s`：两人登桥，脚步缩短，镜头从远景缓慢推近。
- `19-21.5s`：中央停步、抬手、指尖相距一线；音乐收窄并出现心跳。
- `21.5-24s`：冻结，字幕出现：`他们等了一年，才见这一面。`
- 用户可点击右下角将速度切换为 `1x / 1.8x / 3x`，画面与音乐同步。

### 2. 黑场反转 / 3 秒

- 指尖即将相触时音频在 180-260ms 内抽空。
- 画面硬切纯黑，仅保留轻微胶片颗粒。
- 两行文字依次出现：`他们相会了。`、`而今晚，我决定先去见一见自己。`
- 鹊桥弧线碎成四颗星，四颗星成为下一幕入口，不使用普通页面淡入。

### 3. 单人宇宙 / 四个分支

四颗星为 `AI / GAME / ANIME / CITY`。进入分支时，所选星在原位放大并接管全屏；退出时奖励星沿桥弧返回中央。每个分支都遵循“聚拢 -> 爆开 -> 中央媒体 -> 完成反馈 -> 回收”的空间语法，但拥有不同镜头语言。

- **AI**：官方图标沿轨道聚拢，选择陪伴角色后卡片向四角爆开，中央 `ai-shinjuku` 视频从极小透视状态放大；点击可进入黑色全屏播放器。
- **GAME**：冰蓝世界起场，长按充能；图片按节拍 match-cut，完成时红色画面和兼容版原神视频接管中央。
- **ANIME**：五张横向画面成为可拖动胶片，黑帧和遮罩扫过完成切片；选中后中央分镜扩展为全屏。
- **CITY**：真实夜景构成三条路线，拖动光点沿桥弧行走；到达终点后获得 CITY 星。

### 4. 星辰回收 / 8-12 秒

- 用户必须亲自点击或拖动至少两颗已获得的星回到中央。
- 星的飞行轨迹沿同一条共享弧线，弧线逐段重新点亮。
- 全部星回收后，星尘重新组成开场的鹊桥，但桥上只出现一个人的剪影。

### 5. 尾声 / 二次互动

- 文案：`牛郎织女每年相会一次。`、`我今晚，先和自己见面。`
- 第一次点击只改变按钮文案：`你真的想结束今晚吗？`
- 第二次点击，内容坍塌、旋转离场；白色圆幕从按钮位置扩张覆盖全屏。
- 极简白屏只留下：`一个人的七夕，也不是被剩下。` 和重播入口。

## 视觉系统

- 神话段：近黑夜空、冷白星光、克制金色桥弧；文字退居镜头边缘，人物是主角。
- 单人段：黑、纸白、信号红、冷蓝四种对比色；禁止一整页同色渐变和装饰光球。
- 字体层级：标题使用高反差中文宋体，HUD/时间/状态使用等宽体，正文使用清晰黑体。
- 卡片圆角不超过 6px；媒体以全屏和无框画面为主，不套多层卡片。
- 桥弧是全站唯一共享视觉母题：鹊桥 -> 轨道 -> 地平线 -> 胶片切线 -> 城市路线 -> 星座 -> 新鹊桥。

## 动效与技术架构

- `CinematicStage`：一个持续存在的高 DPR Canvas，绘制星尘、喜鹊、人物、桥和碎裂星；只保留一个 RAF。
- `MotionDirector`：GSAP 主时间线管理 DOM 镜头、共享弧线、媒体爆开、全屏播放器和尾声。
- `AppController`：显式状态机管理 `preload / bridge / reversal / hub / world / constellation / outro / final`，每一幕有 `enter/exit/pause` 生命周期。
- 音频由用户手势启动；主时间线优先读取音频时钟，静音时使用 `performance.now()`；速度变化同步修改音频 playbackRate。
- 预定动画只改变 `transform`、`opacity` 和必要的 `clip-path`。离场后暂停 Canvas、视频和 GSAP 时间线。
- `prefers-reduced-motion` 保留叙事状态和交互，只取消步态、视差、粒子与长镜头。

## 输入与可访问性

- 关键推进只依赖明确按钮；滚轮和方向键只作为辅助，不在拖拽、长按和视频状态中抢夺输入。
- 所有图标按钮有可读 `aria-label`，焦点态清晰，触控目标至少 44px。
- 手机端字幕固定在安全区内的底部单句，角色舞台保持无遮挡。
- 使用 `100dvh`、safe-area 和独立竖屏构图；验证 `390x844` 与 `430x932`。

## 验收门槛

- 开场连续运动不少于 20 秒，人物至少完成 6 步且四肢可见摆动。
- 相遇前必须有减速、停顿、伸手和静音反转，不能直接切页。
- 四个世界至少 AI、GAME、ANIME 使用现有真实视频/图片并完成中心媒体爆开。
- 桥或星必须跨幕连续，不允许每幕重新伪造一个无关对象。
- 桌面和两档手机无标题遮挡人物、无溢出、无黑色视频、无控制冲突。
- 单测、构建和浏览器完整核心流程全部通过后才发布。
